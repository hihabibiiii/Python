# 🐍 Python Practice — Complete Beginner to OOP

A structured collection of **50 Python topics** with hands-on practice questions, organized progressively from the very basics to Object-Oriented Programming (OOP). Built as part of a **Data Science learning journey**.

---

## 📁 Repository Structure

Each folder is numbered and named after a specific Python concept, containing multiple `question_XX.py` files for practice.

```
Python_Practice/
├── 01_Variables/
├── 02_Data_Types/
├── 03_Input_Output/
├── 04_Type_Casting/
├── 05_Operators/
│   ...
└── 50_Encapsulation/
```

## 🚀 Getting Started

### Prerequisites
- Python **3.8+** installed → [Download Python](https://www.python.org/downloads/)
- Any code editor (VS Code recommended)

### Run a Practice File
```bash
# Navigate to any topic folder
cd 01_Variables

# Run a question file
python question_01.py
```
